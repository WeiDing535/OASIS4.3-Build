# Experimental native components

Opt-in modules include contextual seed search, bounded weak-density growth, batched composition-preserving permutation nulls, local sequence anchors, fragment joining and discriminant assembly. They remain research components rather than broadly validated structure-solving defaults.

The repository includes component tests and unrelated training templates, not historical target-data experiments. Native and external composite methods must be evaluated separately, using explicit endpoint and free-set policies. See README.md and GUI_GUIDE.md for the supported source launch workflow.
