# P+ 多流程探索：实验性命令行模式

新增入口 `oasis portfolio --config inputs.json --output 新目录 --workers 2`。
配置文件使用单流程 `pipeline_report.json` 内的 `config` 对象，不能把整个报告作为配置。
`--check` 只做只读预检，不创建输出。现有 GUI 和单流程默认行为保持原样；GUI 尚无此模式的按钮。

预设四条分支：原始 P+ / Wang14、原始 P+ / Wang8、稳定性收缩 P+ / Wang14、原始 P+ / Wang8 加精修权重搜索。
四条均启用已有的序列清理及单拷贝部分模型清理，遵守其适用性检查。复杂序列或多拷贝不满足清理条件时保留原模型。
共同输入、自由集、随机种子、建模轮数和每轮精修次数相同；精修权重搜索分支另有固定的四次工作集试精修，计算成本更高。
不按中途 Rfree 提前停止。可用 `--protocols` 选择预设分支子集，选择在计算前记录。

最多并发两条完整流程，每条引擎线程数固定为 1。权重搜索内部最多并发两次试精修，所以两条流程并发不等于整个程序最多两个子进程。
失败分支保留日志并不阻断其他分支。取消时保留各分支检查点。现阶段不支持组合任务自动续跑；重新运行必须用新目录。

自动评估不读取 Rfree：先以键长 RMSD≤0.030 Å、键角 RMSD≤3.0° 和正的序列锚定覆盖为宽松的复核门槛；
再比较唯一序列覆盖、重复比例、未锚定残基比例和工作集 R。采用 Pareto 比较：只有一个候选不被其他候选在这些指标上支配时，才给出暂定推荐。
多候选各有优劣则不宣布唯一胜者，展示最多三个优先复核候选；所有分支都保留。
序列覆盖只统计长度至少 12 的唯一精确匹配锚，按预设拷贝数限制重复计数；它是保守支持度，不能等同于精确坐标正确率。
这些门槛是经验策略，不是完整结构的验收标准；与权重试精修的严格门槛分开。
键长/键角 RMSD 衡量约束符合程度，不是完整的结构立体化学验证。工作集 R 也可能偏爱过拟合，因此推荐仅供复核。

输出包含 PLAN、SOURCES、INPUTS、PROGRESS、PORTFOLIO_REPORT JSON，以及可读 REPORT.md。
结果报告展示原始 Rfree，但不参与推荐。推荐模型沿用各自分支的坐标文件和 SHA256，不产生自动合并模型或相位。
这些流程来自已知开发案例，不能据此宣称最终 Rfree 是完全独立的盲验证分数，也不能保证达到 30%。

这里的“权重搜索”指 REFMAC `WEIGHT MATRIX` 的数据与几何约束平衡，不是相位合并。
候选 0.005、0.01、0.02、0.04 及几何阈值均为预设经验策略。试精修屏蔽原自由集观测，选择符合门槛的最大权重；
最终从试精修前的清理模型重新开始，用原始观测和自由集固定精修 30 次。NSF-D2 已有结果中选中 0.02，Rfree 31.34%→31.28%。
该数值是上一轮已有结果，不是新增并行模式已经取得的改善。
