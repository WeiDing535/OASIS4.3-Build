# OASIS4.3 dev6：默认多流程 P+ 与 GUI

新建任务默认选择 P+ 自带引擎，并启用多流程探索。四条固定流程分别为 P+ / Wang14、P+ / Wang8、稳定性收缩 P+ / Wang14、P+ / Wang8 加工作集精修权重搜索。默认最多两条流程同时运行，可选择单条并发以节省内存。

GUI 显示分支状态、各自 Rwork/Rfree、唯一序列覆盖、暂定推荐及每个模型下载入口。原始 Rfree 仅展示，不用于推荐或提前停算。没有唯一优势候选时展示多个结果供复核，不自动合并相位或模型。若多个优势流程输出文件 SHA256 完全相同，则明确标为等价结果，展示一个代表用于预览与下载；保留原排名记录及各流程文件，不把等价代表误称唯一流程推荐。工作集拟合、精确序列支持和几何偏差仅构成经验推荐依据，不保证坐标正确。

关闭“多流程探索”可回到原单流程；导入不含 explore 字段的旧配置时按原单流程执行。单流程的部分模型清理、精修权重搜索、稳定性及 Wang 半径设置也可在 GUI 中保留、导入及导出。

dev6 已完整复跑胰岛素、P9、SEC17 的四分支默认模式：GUI 推荐/代表终点分别为 Rfree 24.00%、28.60%、25.88%。SEC17 两条优势流程的模型 SHA256 完全相同，显示 Wang8 代表；稳定性分支报告 25.78%，但不按 Rfree 选择。NSF-D2 沿用此前 dev5d 完整四分支验证的 31.28%，本次完成 dev6 GUI 导入与下载核验，既有数值代码未变，没有将其记为本次 dev6 新复跑。

旧单流程终点分别为胰岛素 24.94%、P9 27.35%、SEC17 27.42%。新流程并不保证每个终点都低于旧值；P9 的新推荐 28.60% 使用清理后精修。当前新 Wang14 原始末轮为 27.23%，清理后固定低权重精修变为 30.32%；权重搜索分支恢复至 28.60%。原始末轮和各流程数据均保留，关闭多流程仍可采用原单流程。

第三方引擎及 Python 沿用已有本机授权组件，不另装 Phenix 或 CCP4。完整套件未随包安装，但包括 Phenix 衍生 RESOLVE/CCTBX 等第三方内核；本机评估及再分发限制继续适用。旧独立包与旧结果保持原状，发布到新的 dev6 目录。

本次主要更新运行调度、结果适配和界面。既有数值算法没有修改；原流程的 Wang 阶段标题改为按实际配置显示半径，避免 Wang8 仍标为 Wang14。旧检查点应使用其原始版本恢复，不跨版本续跑。
