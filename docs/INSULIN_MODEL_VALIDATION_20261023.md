第三列改善不能直接解读为完整模型质量提升：候选中重建的 Cys 和三个新增残基只有 N/CA/C/O，缺少侧链，因此碰撞、rotamer 和 Cβ 统计的原子/残基分母也改变了。未建 A1–A2 不包含在上述 15 个缺失原子中。

原模型的具体问题以文件链号表示：

- `A21 GLU` 是 Ramachandran 离群点；`A20 GLY–A21 GLU` 的 omega 约 128.42°，为扭曲肽键。这是生物学 B 链的 20–21 位。
- `B1 CYS` 同时有 rotamer 离群和 Cβ 偏差；`B9 TYR` 也有 Cβ 偏差。它们对应生物学 A6 和 A14。
- 本轮没有通过额外全局精修消除这些问题，也没有仅凭较低 Rfree 宣布模型正确。

## 端点补建与固定预算对照

1. 从上一轮最终 refined.mtz 的 FWT/PHWT 构建归一化密度图，使用现有 `terminal_candidates`，target=None，beam_width=6，保留原有密度、肽键和碰撞阈值。固定现有端点向前生长，没有任何通过筛选的候选。
2. 使用现有算法的一残基端点修复规则：移除当前 A6 主链作为可重建端点，A7 及其后主链固定；一次搜索最多重建 A6 并尝试 A5 到 A1。按图上 gain 排序，且要求重建 A6 的 profile 比原值至少高 0.1；不使用 Rfree 排序。
3. 原 A6 profile 3.7449，重建后 4.4389；随后 A5/A4/A3 profile 为 3.8609/3.0008/3.6000。最高 gain 候选支持重建 A6 并新增 A3–A5（VEQ）。继续到 A2 的 profile 为 1.9400，未满足终端接受阈值；A1 没有可继续的候选。只保留通过现有条件的前缀。
4. 将同一原始 46 残基模型和这个 49 残基部分主链候选，分别使用同一份原始观测、原始自由集、observation-only HL，固定追加 10 个 REFMAC cycles。两组都使用最后一轮结果，不按 Rfree 选轮次；原始自由集保持检查均通过。

49 残基候选的生物学 A 链为 `VEQCCASVCSLYQLENYCN`（A3–A21），仍缺 `GI`（A1–A2）；生物学 B 链 30 残基保留。临时文件沿用原有编号，新增残基编号为 B-2/B-1/B0，分别对应 A3/A4/A5；B1 对应重建的 A6。

侧链缺失清单：Val A3 缺 CB/CG1/CG2；Glu A4 缺 CB/CG/CD/OE1/OE2；Gln A5 缺 CB/CG/CD/OE1/NE2；Cys A6 缺 CB/SG。故该候选用于继续建模，不能作为完整成品。

## 结果文件与可复核性

- `baseline_validation.out` / `validation_details.json`：原模型独立验证，包括逐残基离群点。
- `sulfur_pairs.json`：六个 Cys 的所有两两最近像距离和对称代码。
- `terminal_check.json` / `terminal_repair_check.json`：固定端点失败及一次端点修复候选、所有接受阈值与逐步记录。
- `candidate49_backbone.cif`：精修前部分主链候选。
- `baseline46/model.cif` / `candidate49/model.cif`：固定 10-cycle 对照后的两份模型。
- `baseline46/refined.mtz` / `candidate49/refined.mtz`：相应图系数和精修输出。
- `comparison.json`：精修完整统计、工具指纹、自由集检查和协议限制。
- `baseline46_validation.out` / `candidate49_validation.out` 及相应 `_details.json`：两组独立几何验证。
- `model_completeness.json`：缺失重原子清单及 A6–A11 可评估性。
- `BASELINE.json` / `source_integrity.json` / `ARTIFACT_MANIFEST.json`：输入来源、协议、源文件完整性和产物哈希。

这些属于同一数据集上的诊断，不是盲测。生长用的是下游精修图，未证明完全排除自由反射信息；Rfree 应保留为诊断指标，不能宣称独立端到端验证。没有重新划分自由集、引入目标参考坐标、安装依赖或覆盖历史产物。
