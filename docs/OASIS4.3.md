# OASIS4.3 精简开发版

只提供一条流程：**选择定相方法 → 对应的密度修饰 → 可选的 Buccaneer / REFMAC**。

“启用 Buccaneer 模型构建与 REFMAC 精修”默认开启。手动关闭后，流程在密度修饰后成功结束，只执行输入核验、定相、密度修饰三个阶段，分别保存定相结果、纯观测 HL、最终相位/FOM 和日志，并提供“下载最终相位 MTZ”。不检查或调用外部建模精修引擎，无需安装或配置 Buccaneer/REFMAC；仍需原始观测及自由集、序列、重原子和通用 DM 参考 MTZ。

| 定相方法 | 密度修饰 | 后续处理 |
| --- | --- | --- |
| 连续 SAD（默认） | MLHL-best | 无种子模型的 Buccaneer 构建与 REFMAC 观测 HL 精修 |
| 直接法 P+ | Legacy | 同上 |

默认方法不表示对所有样品更好。两种方法保留现有 OASIS Python 数值实现，未修改上游数值源文件，也不宣称与历史 Fortran OASIS 数值等价。其他独立建模、模型延伸、单独精修、独立 R 因子、训练、混合算法、重原子搜索等入口不在精简版界面及专用源码包中。开发仓库保留旧源文件和测试，以便回溯；这些文件不作为本版产品功能。

## 启动

本机已准备专用 `.conda-unified` 环境（Python 3.12）。双击 `OASIS4.3.command`，或者在此环境中执行 `python -B run_desktop.py --project .`。

界面是原生桌面窗口（Tk，随 Python 运行时提供）：不启动网页服务、不监听端口、不需要浏览器或端口转发，任务与数据全部留在本机。窗口左侧是输入表单，右侧分“任务记录 / 运行日志 / 精修结果 / 结构 3D / 运行计划”五页，底部是进度条与“新建任务 / 开始运行 / 停止 / 打开结果目录 / 导出结果… / 导入已有结果…”按钮。表单末尾的“检查配置”只做只读预检，不改动任何文件。

表单只显示每次实验都要填写的参数（定相方法、输入文件、样本与密度修饰、建模与精修）；标定常数与运行资源默认隐藏在“显示高级参数”之后，展开后按“输入细节 / 循环与采样 / P+ 优化 / 运行资源与终点组合”分组。隐藏只影响显示，不改变任何默认值。“新建任务”（⌘N / Ctrl+N）清空表单、回到默认值并建议一个新的输出目录，任务记录不受影响。

“导出结果…”把当前任务的整个输出目录复制到用户选择的位置（模型、相位 MTZ、逐轮报告、`endpoint_selection.json` 与日志）；“精修结果”页顶部画出 R-work（实线）/ R-free（虚线）随轮次变化的曲线，图例给出最新数值，下面的表格与曲线来自同一份逐轮报告；“保存最终模型…”单独另存最终模型。“结构 3D”页用窗口内的 Canvas 显示最终模型的 Cα 主链，拖动旋转、滚轮缩放，可切换为全部原子，不需要浏览器或外部查看器。

“任务记录”页持久保存本机跑过的任务（开始时间、状态、方法、最终 R-work、输出目录），点选一行即可回看该任务的日志与终点网格，双击打开结果目录；记录写在 `<项目>/.gui-oasis/jobs`。“导入已有结果…”登记的既有目录状态显示“已导入（仅查看）”，只用于回看曲线/表格与导出，不会重新运行。多个任务可以同时运行（上限 4 个），各自使用独立输出目录、日志与子进程组，启动后表单自动给出新的目录建议，便于连续排队。

“显示高级参数”里的**反馈终点组合**（如 `2,3`）与**反馈终点溶剂组合**（如 `auto,0.5`）对应命令行的 `--feedback-endpoints` / `--dm-solvents`：留空等价于单终点，即按“密度修饰周期”跑一遍；填写后每个终点各跑一遍同一协议，最后只按工作集 R 选终点，不读 R-free。“精修结果”页显示被保留终点的统计，`endpoint_selection.json` 记录全部终点的数据与选择规则。

## 输入

- **SAD MTZ**：平均振幅及标准差、异常差及标准差，或完整 F+/F− Friedel 对。不需要已有相位。
- **原始观测 MTZ**：当前精修协议固定使用唯一的 `F`（F 型）、`SIGF`（Q 型）、`FreeR_flag`（I 型）。必须保留原自由集；不能包含下游 FWT、PHWT、FOM、SAD_HL 列。列齐全时可与 SAD 使用同一文件。
- **重原子 PDB / mmCIF**：已有重原子信息，正确手性和设置；本版不做搜索、选手或隐式重索引。
- **序列**：标准 20 种氨基酸 FASTA/PIR，多条记录分别代表不同链。整个文件的 ASU 份数由用户提供；不自动推断，不包含自动 SeMet 组成转换。
- **f″**：对应实验波长的正数，按元素写 `S=0.56` 或 `Se=3.8`；多元素以逗号分隔。
- **输出目录**：必须尚不存在；不覆盖已有任务。

SAD 与原始观测必须使用相同晶胞、空间群 Hall 设置及合并后的倒易 ASU 索引。原自由集通过精确 HKL 连接；不重新划分自由集，不改写原输入。

- 主要结果、相位/地图、运行记录、日志、逐轮记录分组下载。开启建模时只有完整流程和模型哈希核验通过后才标记并提供“最终模型”；关闭建模时，核验最终 DM 文件哈希后提供“最终相位 MTZ”，不显示 R 因子或模型预览。失败时保留中间结果并显示失败阶段。
- 实时日志跟随当前 SAD、DM 或当前轮 Buccaneer/REFMAC；最终可以下载完整阶段日志。

输出目录的 `00_sad_to_model` 包含：

关闭建模时仅生成 `01_inputs`、`02_sad`、`03_dm` 和流程记录，不生成建模序列、地图适配目录、模型或精修结果。

1. `01_inputs/`：带原自由集的 SAD、输入核验；开启建模时还包含副本展开后的建模序列。
2. `02_sad/experimental.mtz`：原算法的 DM 前 PHIB/FOM 与 HL，P+ 还保留 PPLUS；同目录 `observations.mtz` 单独保存纯观测似然 HL 及其矩，作为固定精修先验。
3. `03_dm/map_phases.mtz`：密度修饰后的相位、FOM 和独立元数据。
4. `04_bridge/building.mtz`：原始 native 加 `FWT = F × 最终 DM FOM`（仅一次）与 PHWT；初始自由反射地图系数保持缺失。
5. `05_build/`：每轮 Buccaneer、REFMAC、精修地图与日志。
6. `primary_model.cif`、`pipeline_report.json`：固定末轮模型与可追溯流程记录。

自 4.3.0.dev2 起，明确分开三类文件：原定相结果 `experimental.mtz`、纯观测似然 `observations.mtz` 和 DM 后验 `map_phases.mtz`。连续 SAD 的原定相 HL 含最终三重相位关系与部分结构场，只供原有 DM 路径使用；精修观测 HL 用原算法已拟合的异常尺度和误差参数重建，不包含这些附加场，也不重新拟合尺度。P+ 原 HL 已是误差校准的观测似然，其 HL 数值直接保留到独立文件；独立文件 PHIB/FOM 是该观测分布的矩。P+ legacy DM 仍在需要时从原定相结果做矩匹配，不能保留完整分支形状。REFMAC 每轮固定使用 `observations.mtz`，不以定相、DM 或模型后验替换。上游定相和 DM 源码及输出保持不变；精修先验协议发生了显式变更。

FOM 是算法内部置信度，不能当作真实相位准确度或直接跨方法排名。SAD/DM 排除原自由集；后续外部地图尚未认证为仅工作集，Rfree 不是端到端独立盲测指标。Cα 预览不替代详细化学与结构验证。

## 中断恢复与版本保留

停止会清理子进程，保留阶段文件。CLI 使用同一组参数加 `--resume` 恢复；程序核验输入、运行资源、环境、代码与完成文件哈希，通过后跳过已完成阶段，未完成目录改名保留。重跑阶段前，旧日志另存为 `<阶段>.interrupted-<唯一标识>.log`，记录路径和哈希，并保留在结果下载列表；当前日志只记录最新尝试。GUI 暂无恢复按钮。切换建模开关，或更换算法、参数、代码、输入后需要新目录，不允许将旧检查点混用。

## 验证范围

两种定相入口在合成观测上与保留的原版 CLI 输出逐列一致，两种 DM 分别与原版引擎比较通过；原始 HL、PPLUS、工作集、FOM 交接和方法切换恢复限制都有测试。自动化整合测试中的 Buccaneer/REFMAC 是替代程序；不把这些测试称为真实数据完整解结构验证。

CLI 默认开启建模；添加 `--no-build-model` 仅运行定相与密度修饰，`--build-model` 显式开启。图形界面导入/导出配置会保存 `build_model` 布尔值。关闭时运行报告中的 `primary_model` 为 null，`dm_phases` 是最终相位文件；这属于成功完成，并非建模失败。


2026-10-23 首轮恢复（4.3.0.dev1）的完整回归为 388 项通过、1 项参考数据测试排除。该旧版曾用 CCP4 官方胰岛素实测 S-SAD 数据做默认参数探索性运行：两条路线均完成定相和 DM，但连续 SAD 的末轮衍射拟合很差，P+ 后续构建产生空模型；未建立成功解结构的真实数据案例。教程 HYSS 位点的正确手性尚未独立确认。这些结果不能作为两种方法准确度排名，也不改变现有数值默认值。

4.3.0.dev2 的诊断发现：旧连续 SAD 完整后验作为固定精修先验会显著加剧本例发散；新的观测先验文件用于纠正这一交接。旧版与新版运行必须使用不同目录，不能混用检查点；后续验证与结果分别记录。
