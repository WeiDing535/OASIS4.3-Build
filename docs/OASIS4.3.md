# OASIS4.3 精简开发版

只提供一条流程：**选择定相方法 → 对应的密度修饰 → Buccaneer → REFMAC**。

| 定相方法 | 密度修饰 | 后续处理 |
| --- | --- | --- |
| 连续 SAD（默认） | MLHL-best | 无种子模型的 Buccaneer 构建与 REFMAC 原始 HL 精修 |
| 直接法 P+ | Legacy | 同上 |

默认方法不表示对所有样品更好。两种方法保留现有 OASIS Python 数值实现，未修改上游数值源文件，也不宣称与历史 Fortran OASIS 数值等价。其他独立建模、模型延伸、单独精修、独立 R 因子、训练、混合算法、重原子搜索等入口不在精简版界面及专用源码包中。开发仓库保留旧源文件和测试，以便回溯；这些文件不作为本版产品功能。

## 启动

本机已准备专用 `.conda-unified` 环境（Python 3.12）。双击 `OASIS4.3.command`，或者在此环境中执行 `python -B run_gui.py --project .`。界面仅监听本机回环地址，任务与数据保存在本机。

从专用源码包新建环境时：

```bash
conda env create -f environment.yml
conda activate oasis43-unified
python -B run_gui.py --project .
```

源码包不包含外部引擎运行时。完整安装包需一并提供 Buccaneer、REFMAC、对应共享库、字典与参考资源，用户使用完整包时无需另装 CCP4。现存 Intel Mac 0.8.3 包仍是旧版，不包含本次精简界面；新的整合完整安装包尚未生成。

## 输入

- **SAD MTZ**：平均振幅及标准差、异常差及标准差，或完整 F+/F− Friedel 对。不需要已有相位。
- **原始观测 MTZ**：当前精修协议固定使用唯一的 `F`（F 型）、`SIGF`（Q 型）、`FreeR_flag`（I 型）。必须保留原自由集；不能包含下游 FWT、PHWT、FOM、SAD_HL 列。列齐全时可与 SAD 使用同一文件。
- **重原子 PDB / mmCIF**：已有重原子信息，正确手性和设置；本版不做搜索、选手或隐式重索引。
- **序列**：标准 20 种氨基酸 FASTA/PIR，多条记录分别代表不同链。整个文件的 ASU 份数由用户提供；不自动推断，不包含自动 SeMet 组成转换。
- **f″**：对应实验波长的正数，按元素写 `S=0.56` 或 `Se=3.8`；多元素以逗号分隔。
- **输出目录**：必须尚不存在；不覆盖已有任务。

SAD 与原始观测必须使用相同晶胞、空间群 Hall 设置及合并后的倒易 ASU 索引。原自由集通过精确 HKL 连接；不重新划分自由集，不改写原输入。

## 所有可用参数

| 分组 | 选项 | 默认值 / 范围 | 生效范围 |
| --- | --- | --- | --- |
| 方法 | 连续 SAD / 直接法 P+ | 连续 SAD | 与对应 DM 固定配对 |
| 样品 | 整个序列文件的 ASU 份数 | 1；1–100 整数 | 组成、溶剂估算和建模序列 |
| 样品 | 溶剂比例 | 留空自动估算；指定时严格在 0–1 之间 | 密度修饰；预检查显示实际使用值与来源 |
| 定相 | 迭代周期 | 5；1–100 | 所选方法 |
| 密度修饰 | 周期 | 5；1–100 | 对应的 DM 引擎 |
| 构建精修 | 轮数 | 5；1–20 | 每轮 Buccaneer 后接 REFMAC |
| 精修 | 每轮周期 | 10；1–200 | 每轮固定取最后周期 |
| 连续 SAD 高级参数 | 三重相位关系权重 | 0.1；0–1 | 连续 SAD |
| P+ 高级参数 | AOE | 0.5；严格介于 0–1 | P+ 误差权重目标 |
| P+ 高级参数 | 相位差秩拟合 | 关闭 | P+ |
| 共同高级参数 | kmin | 0.03；0–1 | 三重相位关系阈值 |
| 共同高级参数 | 邻居上限 | 600；0–10000 整数 | 0 表示不截断 |
| 共同高级参数 | 每目标关系上限 | 96；0–4096 整数 | 0 表示不截断 |
| 运行 | 随机种子 | 20261023；0–2147483647 | P+ / DM 随机步骤；连续 SAD 定相本身为现有确定性算法 |
| 自由集 | 原自由集数值 | 0；0–999 整数 | 必须与原始数据定义一致 |
| 列映射 | SAD 映射 | 留空自动识别 | `f=FP,sigf=SIGFP,dano=DANO,sigdano=SIGDANO` 或 `fplus=F(+),sigfplus=SIGF(+),fminus=F(-),sigfminus=SIGF(-)` |
| 资源 | DM 参考 MTZ | 随资源自动填写 | 通用无关参考，不是目标完整结构 |
| 资源 | 外部引擎运行目录 | 自动发现随包资源或本机配置 | 需 cbuccaneer、refmac5 及完整库、字典、参考 |

设为 0 的关系上限可能增加时间和内存；默认 600 / 96 是明确的有限关系搜索设置，不表示完整无截断计算。方法专属参数在另一方法下不生效。预检查会列出生效参数、样品/自由集统计、固定协议和五个阶段。

固定设置：Buccaneer 首轮 3 周期、后续每轮 2 周期；单线程；首轮没有蛋白种子模型，后续使用本任务上轮模型和精修图；REFMAC 每轮保留相同原始实验 HL；最终模型取预先指定的最后一轮，不根据 Rfree 选模。

## 结果与日志

- 五阶段进度：输入、SAD、DM、地图适配、Buccaneer/REFMAC；构建精修显示当前轮次和子阶段。
- 原始 SAD 与 DM 的反射数、平均 FOM、空间群、分辨率、溶剂比例及来源；DM 各周期平均 FOM 轨迹。
- 每轮 REFMAC 的 Rwork/Rfree、周期和原自由集保留核验；Cα 残基/链数、ASU 预期数与可旋转的主链预览。
- 主要结果、相位/地图、运行记录、日志、逐轮记录分组下载。只有完整流程和模型哈希核验通过后才标记并提供“最终模型”。失败时保留中间结果并显示失败阶段。
- 实时日志跟随当前 SAD、DM 或当前轮 Buccaneer/REFMAC；最终可以下载完整阶段日志。

输出目录的 `00_sad_to_model` 包含：

1. `01_inputs/`：带原自由集的 SAD、副本展开后的建模序列和输入核验。
2. `02_sad/experimental.mtz`：密度修饰前 PHIB/FOM、原始 HLA/B/C/D，P+ 还保留 PPLUS。
3. `03_dm/map_phases.mtz`：密度修饰后的相位、FOM 和独立元数据。
4. `04_bridge/building.mtz`：原始 native 加 `FWT = F × 最终 DM FOM`（仅一次）与 PHWT；初始自由反射地图系数保持缺失。
5. `05_build/`：每轮 Buccaneer、REFMAC、精修地图与日志。
6. `primary_model.cif`、`pipeline_report.json`：固定末轮模型与可追溯流程记录。

原始 SAD HL 始终与 DM 后验分开。P+ 的原始 HL 是观测似然，不一定与最终 P+ PHIB/FOM 同矩；legacy DM 按原版规则从最终相位/FOM 做矩匹配（不能保留完整分支形状）。这份 DM 先验不替换 REFMAC 使用的原始实验 HL。

FOM 是算法内部置信度，不能当作真实相位准确度或直接跨方法排名。SAD/DM 排除原自由集；后续外部地图尚未认证为仅工作集，Rfree 不是端到端独立盲测指标。Cα 预览不替代详细化学与结构验证。

## 中断恢复与版本保留

停止会清理子进程，保留阶段文件。CLI 使用同一组参数加 `--resume` 恢复；程序核验输入、运行资源、环境、代码与完成文件哈希，通过后跳过已完成阶段，未完成目录改名保留。GUI 暂无恢复按钮。更换算法、参数、代码或输入后需要新目录，不允许将旧检查点混用。

## 验证范围

两种定相入口在合成观测上与保留的原版 CLI 输出逐列一致，两种 DM 分别与原版引擎比较通过；原始 HL、PPLUS、工作集、FOM 交接和方法切换恢复限制都有测试。自动化整合测试中的 Buccaneer/REFMAC 是替代程序；不把这些测试称为真实数据完整解结构验证。
