# dev8：MTZ 列选择与单文件 SAD 输入

新任务默认固定 pplus_w8_weight，界面直接读取并选择 SAD 四列振幅、平均 F/σF 及已有自由集标记。多组候选时要求明确选择，不静默猜测。下拉框同时显示 dataset、列名、类型与列索引，因此重复列名也可精确指定。

原始观测 MTZ 为可选；空白使用 SAD 文件。优先采用明确选择的平均振幅；没有平均振幅时，从明确选定的 Friedel 对生成算术平均，sigma=hypot(sigma+,sigma-)/2；只测到一侧的观测保留，SAD 定相不伪造另一侧。当前内核接受振幅，不会把 I(±) 强度冒充 F(±)，界面会要求先完成强度转振幅。

原自由集按 HKL 保留。观测文件没有自由集但 SAD 有，则使用 SAD 原标记；缺少对应 HKL 的标记时拒绝运行，不补造原标记。所有输入都没有自由集时，用种子和 canonical-ASU HKL 的 SHA256 排序生成 5% 自由集，标记为新建，Rfree 不可与原自由集结果直接比较。已有自由集不允许重建。

标准化副本保留原观测 dataset 名称、project/crystal 名称、晶胞与已有波长元数据，避免改变后续精修语义；这些元数据不会填充或替代界面必填的实验 SAD 波长。

只在新输出目录 01_inputs 内生成标准化副本；原文件不修改。实际列索引、标签、dataset、类型、平均值来源及自由集来源记录于 columns.json 和 pipeline_report.json，核验界面在计算前展示这些信息。波长仍必填且不推断，f″仍由元素与显式波长自动计算。

本次用户任务已经完成 SAD 和 DM，Buccaneer 第 1 轮 8 残基、Rfree64.88%，第 2 轮空模型。列界面修复不等于这组数据已求解；新 GUI 展示具体失败阶段及原因，不把空模型或上一轮较差结果标记为成功。旧任务目录保持不变。
