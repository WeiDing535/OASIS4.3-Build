# P+ 第一轮优化：余弦分位数与双峰矩保留

本轮在独立实验模块中实现两项变化，并完成固定预算的 2×2 胰岛素消融试验。组合方案从旧 P+ 的 17 个 Cα、Rfree 0.4954，改善到 **50 个 Cα、Rfree 0.2823**。这是单个公开数据集上的阶段性结果，不是一般性能或盲测结论，也不是原版 OASIS 的数值复现。

产品 GUI、默认 P+ 路线和 `src/oasis_py` 保留源代码未改动。实验代码位于 `src/phasebuild/pplus_experimental.py`；研究脚本、冻结源码、输入指纹、原始失败记录与所有模型位于：

`/Volumes/Fast_4T/GPT_WORK/OASIS4.3-pplus-optimization-20261023-231655/`

## 实现依据与边界

现有可选 rank-fit 在相位偏移角 delta 上做均匀分位数。CCP4 的 [OASIS 文档](https://www.ccp4.ac.uk/html/oasis.html) 描述的是对 cos(delta) 做均匀分布拟合。本轮新增 acentric 余弦分位数拟合，保留 centric 行，并对重复值使用平均秩，避免以 HKL 顺序任意拆分相同值。因保留重复值，输出并不保证严格无重复的均匀经验分布；没有宣称与旧二进制实现完全一致。

第二个问题出现在当前 Python P+ 与 legacy DM 的交接：观测 HL 与最终 P+ PHIB/FOM 不一致，DM 会转成仅匹配第一圆周矩的单峰 von Mises 分布。它保留平均相位/置信度，却丢失相位双解形状。原研究已有在后续相位改善中保留固有双峰分布的动机，见 [2009 年论文](https://pubmed.ncbi.nlm.nih.gov/19923717/)；本轮的具体近似是新的实验实现，不等于该论文算法的复现。

实验实现将两支 P+ 相位视为两个加权 von Mises kernel，令每个 kernel 的第一矩等于原误差衰减 g，再匹配混合分布的第一、第二圆周矩，求四个 HL 系数的最大熵近似。第二矩取决于这个 kernel 假设；更高阶混合矩不保留。中心反射按允许的两个离散相位处理。g 在 0.9999 处有显式上限，失败的矩拟合会报错，不静默退回单峰。

这个双峰近似仅作为 **DM 初始后验**。原始观测似然 HL 单独保留给 REFMAC，不能把结构场或 DM 后验当作新的实验观测。

## 预先固定的试验

四组使用相同原始 SAD/native 数据、原始自由集、独立 Phaser 工作集精修/补全的 7 个硫位点、序列、f''=0.56、seed=20261023 和关系截断。每组定相 5 cycles、相同 legacy DM 5 cycles、从头 Buccaneer/REFMAC 5 rounds、每轮 REFMAC 10 cycles，均报告第五轮末值。不导入连续 SAD 的蛋白模型或完整目标坐标，不按 Rfree 调参或选轮次。

| 方案 | Rwork / Rfree | Cα 数 | 链数 | 结果 |
|---|---:|---:|---:|---|
| 旧 P+ 对照 | 0.4911 / 0.4954 | 17 | 1 | 一个未知残基，拟合差 |
| 仅余弦分位数 | 0.4502 / 0.4604 | 24 | 1 | 部分 B 链，拟合仍差 |
| 仅双峰矩保留，原始运行 | 0.4501 / 0.5114 | 35 | 2 | 有未知残基，未改善 Rfree |
| 仅双峰矩保留，完全相同观测先验补充对照 | 0.4766 / 0.4826 | 21 | 1 | A 链完整，整体拟合仍差 |
| **余弦分位数＋双峰矩保留** | **0.2521 / 0.2823** | **50** | **2** | 两条链序列已指认，仍为部分模型 |

旧对照的定相数组、DM 数组及最终模型均逐位复现上一轮 P+ 结果；最终模型 SHA256 为 `114d24679a4e87a24d3b964fbb97fb95b3b70c062645fc8f530c056495bfebe4`。这也说明组合方案没有通过更换外部引擎或增加轮次获得优势。

双峰组的 DM 交接实际采用 `original_consistent_HL`，而旧组采用 `moment_matched_von_Mises_branch_shape_not_preserved`。矩拟合残差不超过 2×10⁻⁸；真实数据上 g 的上限未被触发。与原 P+ 第一圆周矩的最大差异小于 3×10⁻⁸。经过 MTZ 单精度保存后，HL 与 PHIB/FOM 的矩差异约 2.1–3.5×10⁻⁶，满足现有 DM 的一致性检查。

四组观测来自相同输入、使用相同观测似然公式。旧组、余弦组、组合组的观测 MTZ 数值逐位一致。仅双峰组因 Wilson 优化器末位舍入不同，少量 HL 相差一个 float32 ULP（绝对差最大 1.53×10⁻⁵），因此额外在 `bimodal_exact_prior/` 只重做建模，使用旧对照的观测 MTZ **完全相同字节**，原相位和 DM 产物冻结。补充对照得到 21 残基 A 链，Rfree 0.4826，整体仍未得到可靠解；见 `EXACT_PRIOR_FOLLOWUP.json`。原始运行不覆盖、不删除。

这次微小先验差异导致自动建模分支和最终模型明显变化，暴露了下游循环的数值敏感性。组合组本身已使用与旧对照逐位相同的观测先验，但尚未证明它对类似扰动、其他种子或独立数据集稳定。因此结果支持继续研究组合方案，**不支持立即替换默认算法或宣称稳健改善**。

## 组合模型的独立质量检查

组合模型文件链 A 为生物学 B1–B30，序列完整：

`FVNQHLCGSHLVEALYLVCGERGFFYTPKA`

文件链 B 为生物学 A1–A20：

`GIVEQCCASVCSLYQLENYC`

仍缺生物学 **A21 ASN**；另外已建残基中，生物学 A7 与 B7 各缺一个 SG 原子。因此“50 个 Cα”不代表完整的 50 残基全原子模型。

已安装 Phenix 1.21.2-5419 的 MolProbity 检查结果：

- Ramachandran 离群 0%，favored 97.83%；rotamer 离群 0%。
- clashscore 3.98，MolProbity score 1.22。
- 两处 Cβ 偏差：文件 A1 PHE 0.316 Å、B14 TYR 0.283 Å。
- 没有 omegalyze 离群；这不能代替密度和衍射验证。
- A6–A11 的 SG 距离约 2.190 Å，但 CB–SG–SG–CB 扭转约 59.14°，仍需检查。
- A20–B19 的 SG 距离约 2.027 Å，扭转约 −85.18°。
- A7–B7 因两个 SG 缺失而不可评估，不能宣布三个二硫键均已完成。

原始逐残基检查位于 `combined/validation/details.json`，原子缺失与完整二硫键几何位于 `COMBINED_MODEL_AUDIT.json`。其他三组也独立运行了 MolProbity，包含负结果。各组原子数不同，不能只比较一个整体几何分数。

## 相位参照与外部原版运行限制

与独立工作集 Phaser＋Parrot 计算相位做直接同 HKL 比较，没有搜索手性、原点或整体相位偏移。旧组 DM 平均相位分离为 41.21°，双峰组 39.70°，余弦组 44.72°，组合组 44.51°。这是两个计算结果的一致性，**不是真实相位误差**。组合组的建模改善不能解释为所有相位统计都改善。

尝试了本机 `/Applications/ccp4-9/bin/oasis4-2-1` 的独立工作集定相参照，但程序在加载时退出：它依赖安装包中不存在的旧 `libccp4f.0.dylib` 等动态库。另几个附带 Mac 二进制依赖相同旧路径。未安装依赖、修改二进制或创建不匹配 ABI 的替代链接。失败记录位于 `native_reference/`，本轮没有可用的原版数值一致性结论。

## 测试、使用与后续工作

新增 7 项测试覆盖余弦分位数与重复值、独立高精度积分的 kernel 矩、反足双峰保留、尖锐/非对称分布的前两阶矩、中心反射允许相位、旧 P+ 控制组一致性、原观测 HL 不变以及失败时明确报错。完整回归为 **401 passed，1 reference_data deselected**，证据为 `tests.xml` / `tests.log`。

实验 API：

```python
from phasebuild.pplus_experimental import phase_pplus_trial
trial = phase_pplus_trial(data, composition, heavy, fpp,
                         cosine_rank=True, preserve_bimodal=True)
# trial.raw.hl 是原观测似然；trial.dm_initial.hl 是仅供 DM 的后验近似。
```

本轮精确复现实验入口为上述实验目录的 `run_trial.py`，参数为 `legacy`、`cosine`、`bimodal`、`combined`；每次必须使用新的输出目录，脚本拒绝覆盖已有结果。脚本中的本地路径、既有运行时及数据要求在 `TRIAL_PROTOCOL.json` 与各组 `TRIAL_REPORT.json` 中记录。源码归档属于研究快照，默认产品和 focused source package 不自动启用或包含此未接入入口的实验模块。

下一步优先：

1. 对组合方案补齐 A21 与两个 SG、检查二硫键和 Cβ，并使用固定协议对照精修；不把补模效果混作定相算法的效果。
2. 在独立数据集与已知真值的合成数据上验证两个因素的交互、kernel 假设及误差校准，特别保留仅双峰方案失败的证据。
3. 在建模图和参数选择全过程隔离自由集，再考虑作为明确标记的可选产品协议接入；单个胰岛素案例不足以修改默认算法。
