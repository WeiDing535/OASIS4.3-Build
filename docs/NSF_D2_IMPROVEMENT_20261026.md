# NSF-D2 调研与算法改进：独立版复验

**最终完整独立运行：Rwork 25.50%、Rfree 31.28%，243 个 Cα、2 个片段。原版为 37.42%，改善 6.14 个百分点，仍未达到 30%。**

本轮结果保留真实的非零 P+ 更新，使用 8 Å Wang 掩膜、序列锚定部分模型去重，以及工作集限定的精修权重校准。不是关闭 P+ 后的控制结果。新选项通过独立 CLI 显式启用，未改成 GUI 通用默认。

## 查明的问题

1. 原第五轮有 300 个 Cα、8 个片段。两个主要片段分别精确匹配序列 29–146 和 145–269，重复覆盖两个位置；还有一个已定序重复小段及 50 个未定序残基。第三轮至第五轮继续增生碎片，Rfree 从 33.37% 升至 37.42%。
2. 两个主要片段不能强接：重叠 Cα 在最佳晶体对称像下仍相差约 5.84 Å。新算法保持物理断链，不做任意坐标拟合或补齐缺失区。
3. “必须完整建满 273 个残基才允许清理”的旧门控过严。官方条目本身只有 247 个建模残基，但本轮没有按参考缺失位置裁切。生物学六聚体也不能当作六条 ASU 链。[RCSB 1NSF](https://www.rcsb.org/structure/1NSF)
4. 从 SEC17 继承的 14 Å 掩膜不适合直接当作通用最优设置；本例测试 8 Å 后改善。但不能把 8 Å 推广为所有样品的默认。
5. P+ 关系更新与密度修饰耦合敏感。不更新 P+ 的诊断控制为 31.44%，不能归为 P+ 成果，却说明此例原更新可能放大关系噪声。

## 新增实现

- `partial_model_cleanup.py`：在明确单拷贝 ASU 下，用唯一精确序列锚及原工作集 DM 密度选择非冗余片段。最小锚 12 残基、至少一个 40 残基长锚、覆盖至少 80%；每个序列位置只保留一个候选。不改变保留原子的坐标、占有率和 B，不强接不合理的片段。
- `pplus_stability.py`：把等价三相位约束整体分组，按 HKL 哈希拆分关系组；只有两半支持一致的更新才保留，并收缩到原始概率附近。原始 HL 和 KL 上限不变。这是稳健性启发式，不是独立观测交叉验证。
- `work_weight.py`：以 0.005、0.01、0.02、0.04 各做固定 30 周期工作集试拟合，屏蔽全部原自由集观测且保留标记。按 bond RMSD ≤0.010 Å、angle RMSD ≤1.3° 选择最大合格权重，再从试拟合前模型和原始完整数据重启最终 30 周期。本例选择 0.02；未复用试拟合模型，也未用原 Rfree 选择权重。

## 完整独立运行终点

| 完整流程 | Rfree | 说明 |
|---|---:|---|
| 原版 P+ / Wang14 / 固定第五轮 | 37.42% | 原基线 |
| 稳定性 P+ / Wang14 / 部分模型去重 | 33.47% | 新关系收缩分支 |
| 原真实 P+ / Wang8 / 部分模型去重 | 31.34% | 已从原始输入复现 |
| 上述流程加工作集权重校准 | **31.28%** | 最终完整独立复跑 |

稳定性收缩与 Wang8 的组合反而变差，因此没有简单叠加所有改动，也没有把该研究选项提升为默认。全部控制和不利结果见 `ALL_ENDPOINTS.csv` 与 `ALL_ENDPOINTS.json`。

主要收益来自掩膜和去重。工作集权重校准只使 31.34% 降至 31.28%，不应夸大其收益。新流程增加了明确记录的去重、试拟合和后精修预算，不是相同预算下单独改进 P+ 核心公式的对照。

## 数值与适用性限制

研究脚本的稳定性分支曾得到 32.37%，但与完整流程的种子存在一个 float32 单位的差异，被 DM 和建模放大。清洁单线程环境重新计算后，与完整运行种子逐位一致。因此完整结果采用 33.47%，不以研究脚本数值替代。固定环境不等于跨浮点环境的收敛保证。

本地元数据中的 1.0 Å 不能充分确定教程 `peak.sca` 的真实峰波长；仍明确沿用名义 0.9792 Å。官方 HySS 示例确认这是 1NSF 峰数据并以 8 Se 初搜，但没有独立确认其波长。[官方 HySS 文档](https://phenix-online.org/version_docs/1.8.2-1306/hyss.htm)

条目中的 1.9 Å MAD、ATP/Mg 和沉积 Rfree 不可与本轮 2.400 Å SAD 教程、不同自由集直接比较。未量化 ATP/Mg 缺失对当前误差的贡献，也未将未建模残基全部认定为无序。

这是已反复使用的开发案例。探索配置比较使用了已见分数，不能宣称盲测或普适提升；关系收缩、片段取舍和权重校准内部不用原 Rfree，并不意味着整个开发过程未看 Rfree。Cα 数和序列一致性也不等于坐标正确率。
