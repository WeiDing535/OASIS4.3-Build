# P+ 自带引擎版：独立运行与 SEC17 复验

“独立”按用户已确认的定义：允许随包引擎，但用户无需额外安装 Phenix 或 CCP4。此版本不是所有计算内核均由 OASIS 自行实现。所复制的组件来自本机已有授权发行版，仅供本机研究评估；不代表已取得公开再分发许可。

## 实现

新增明确的方法 `pplus_bundled`：包内原生 Phaser EP_AUTO 从实验工作集及已有重原子子结构计算 SAD 似然，精修并补全重原子位点；保留输入空间群对应的解。随后执行 OASIS 的真实 P+ 条件分支概率更新，包内 RESOLVE Wang14 与 CCTBX classic40 密度修饰，最后使用包内 Buccaneer/REFMAC 构建和精修。要求用户填写实际实验波长，不采用 MTZ 中的占位值猜测。

相位先验与 P+ 地图分别保存：原始观测 HLA–D 固定用于精修；P+ 更新仅输出 PHIB/FOM/PPLUS，未将其反拟合为第二份观测先验。RESOLVE 的起始地图文件只有 HKL/FWT/PHWT，FOM 对振幅只应用一次。密度修饰地图、建模概率字段、精修观测值各自核验。

包内附带科学 Python 3.12；密度内核附带其现有 Python 2.7 和所需 CCTBX、RESOLVE、Phaser 适配模块及动态库。后者来自已有 Phenix 发行版，但不包含完整 Phenix 套件，也不依赖用户另装。旧 `pplus_internal` 近似算法仍标为实验性；不能把自带引擎分支的成功归为该内部近似算法的改进。

## 固定验证方案

SEC17 为既有开发案例，非盲测。输入为原始 SAD、带原自由集的 native、292 残基序列与显式三处 MSE 元素组成、原始五位点实验子结构。未输入目标蛋白完整坐标或旧构建模型。案例沿用此前名义波长 0.9792 Å，不能据此替代其他实验的实测波长。

P+ 参数固定 KL=0.0005、阻尼 0.25、1440 点积分、最多 100 次；此前真实收敛为 49 次。密度修饰为 Wang14 + classic40 (10/20/10)。建模固定五轮，每轮十周期 REFMAC；唯一完整匹配序列链才允许清理，再做固定三十周期振幅似然精修，权重 0.005。终点不按最低中间 Rfree 挑选。原自由集 421 个反射，标记 0，不重新生成。

## 已完成研究复验

新复制的密度内核在屏蔽 /Applications、原科学环境、原引擎包和网络的条件下运行。其 Wang14 与 classic40 输出逐 HKL 与旧成功分支一致。从新地图重新构建得到末轮 Rwork/Rfree=19.39%/27.40%；完整链清理后固定精修为 22.79%/27.42%。该研究运行仍使用独立测试适配器；统一 CLI/GUI 的完整新包复验结果另见研究目录中的 FINAL_AUDIT.json 与 REPORT.md，以实际完成状态为准。

对照组在修正 HKL 连接后固定末轮 Rfree：Parrot3 58.77%、Parrot5 59.77%、Parrot10 56.95%、CCP4 DM40 自动半径 63.44%、DM40/Wang14 55.39%。其他半径和 SHELXE 仅有阶段性探索，不据此声称完成五轮模型验证。

## 发现的问题与修正

1. 研究脚本曾按行拼接排序后的似然和未排序种子，导致 HKL 错位。相关整批结果已标记 invalid-row-join 并保留，不能用于算法判断；已按唯一 HKL 重算上述有效对照。旧 dev4 的生产适配器本来按 HKL 连接，其 61.47% 结果仍有效。
2. 研究脚本曾对已存储的 PHIB 做多余的度→弧度→度转换，最大引入约 1.5e-5 度差异。该运行得到 34.61%，完整保留为 degree-roundtrip-drift。去掉转换、直接保留 MTZ 相位后为 27.42%。这也揭示自动建模离散决策对微小数值变化的敏感性，不能承诺其他平台和案例同样收敛。
3. 新前端适配器曾额外排序实验工作反射，使 Phaser 浮点累加出现小差异。保留输入 SAD 行序，同时仍按 HKL 关联 native，可复现原始四组 HL。没有按 Rfree 调整观测值或目标相位。
4. 从干净启动器运行 CCTBX 时需要明确指向随包的对称操作字典；已由运行时环境设置 CLIBD，避免依赖本机套件环境变量。失败的打包运行保留，不作为成功结果。

## 测试与限制

新增真实接口契约测试覆盖：显式波长、缺失内核时拒绝启动、仅定相时保留所需运行时、native/SAD 行序不同仍正确按 HKL 拼接、自由集排除、保留 SAD 原行序、缺失 HL 采用无信息分布、PHIB/FOM 与 HL 一致、密度内核命令和随包对称字典环境。最终完整测试结果记录于研究目录。

新的应用包与旧 dev3/dev4 包并存；未安装依赖、重置 Git、丢弃原改动或覆盖旧研究结果。公开发布仍需另行确认第三方组件的再分发条件。SEC17 成功仅证明该开发案例可由自包含流程求解，不能推广为所有输入均达到 Rfree 30%。
