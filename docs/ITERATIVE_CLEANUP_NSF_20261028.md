# NSF-D2：每轮精修前清理（dev12，实验选项）

新增 `--per-round-cleanup`，只用于单拷贝ASU、单序列记录、自带P+和DM相位约束。默认关闭，不替换其他案例的设置。高级选项中的同名勾选可启用。

每轮Buccaneer构建后、REFMAC精修前，按原有的唯一序列锚、固定工作集DM密度和连续性约束清理片段。原来的12残基短锚、40残基长锚、80%覆盖及单拷贝门控保持；拒绝时保留当轮原模型。保留原子不改坐标、占有率或B，不强接非物理片段。原始构建模型另存。

NSF-D2的强相位模糊试验从第三轮开始发生工作拟合恶化、覆盖下降及重复片段增加；其37.38%不是旧默认结果，旧默认为30.96%。本轮不启用相位模糊，也不启用DM种子规范化。

相同冻结工作集DM地图、原观测与原自由集下，预先指定末轮：

|---|---:|
| 原5轮＋末轮清理/权重校准 | 30.96% |

每轮清理方案没有增加建模/精修轮数；仍5×10周期，随后沿用原有工作集权重试验及固定30周期末轮处理。第三轮因门控不足拒绝清理，原模型照常保留。八轮对照没有挑第四轮29.64%作为最终值。
