# OASIS4.3 dev7：固定 P+ Wang8 与自动异常散射参数

新任务默认只运行 `pplus_w8_weight` 对应的流程：自带 Phaser 原始 SAD 似然 → P+ → Wang8/classic40 → 固定轮次建模 → 满足门控时的序列清理与工作集精修权重搜索。主界面不再提供其他定相流程、稳定性分支或多流程并发开关。历史模块及既有结果仍保留用于查看和复现。

主输入为重原子元素（例如 Se、S 或 Se,S）和**必填实验 SAD 波长（Å）**。不需要填写 f″；波长也不会从 MTZ 默认字段推断。只有溶剂比例仍可按序列和晶胞估算。

程序使用随包 Gemmi `cromer_liberman`，以 `energy_eV = gemmi.hc / wavelength_angstrom` 计算孤立原子的理论异常散射分量。无需新增依赖或网络访问。支持原子序数 3–92；已知不可靠的重元素极短波长区域予以拒绝。
例如 S / 1.54 Å 得到 f″≈0.5562888691，Se / 0.9792 Å 得到 f″≈3.8415219482。
这些是理论值，不是吸收边扫描实测值。[算法和单位说明](https://gemmi.readthedocs.io/en/stable/scattering.html#anomalous-scattering)。

输入预检展示计算值及来源；`pipeline_report.json` 的 `anomalous_scattering` 和原生前端记录的 `pplus_scattering` 保存波长、能量、f′/f″、算法和 Gemmi 版本。Phaser 的 SAD 似然仍由其内部表按输入波长计算；上述 Gemmi 参数用于 P+ 子结构计算，来源区分明确记录。

旧 CLI 的显式方法和手填 `--fpp` 仅作为兼容接口保留。GUI 导入旧配置时从其 f″字段提取元素名，并明确提示按输入波长重算；没有波长的配置必须补填波长，不能直接运行。

自动理论参数与以前手填值不完全相同，因此旧版 Rfree 不能自动当作本版本成绩。本版本复跑结果以本次验收报告为准。
无需另外安装 Phenix、CCP4 或 Python，但含已有授权第三方计算内核，仍为本机评估包，公开再分发条件未变。

## 本版本完整验收

完整测试：628 passed、1 deselected。实际 GUI 留空波长检查、自动参数预检及完整运行均通过。
