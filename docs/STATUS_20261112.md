# OASIS4.3 当前状态与十案例验收（2026-11-12）

这一页是给评审/接收方看的**单一入口**：程序现在是什么、十案例跑成什么样、和 SHELXE 比在哪个位置、哪些模块是实验性的。细节分散在 `docs/PACKAGED_TEN_CASE_RUN_20261110.md`（打包产物实测）、`docs/SHELXE_BASELINE.md`（SHELXE 对标）、`docs/NO_CCP4_REPLACEMENT.md`（自研模块替换评估）、`docs/LITE_MODULE_20261112.md`（精简版：只做模块 1）。

## 1. 一句话

**定相 + 密度修饰 + 建模精修这条主链已经跑通十个困难案例，10/10 的 R-free 落在独立对照 ±5 个百分点内（中位差 +0.20 pp）；发布形态是"包内自带引擎、接收方持有 CCP4 授权"的私有包，不是可公开再分发的二进制。** 自研的 P+ 定相已达 Phaser 水平，自研密度修饰与自动追踪尚未达到 SHELXE 水平，因此默认关闭、只作研究对比。

流程在界面上拆成三个模块：① P+ 定相（必做）、② Parrot 密度修饰、③ Buccaneer/REFMAC。②③ 依赖本机 CCP4，启动时自动检测：找到就默认勾选，没找到就默认关闭并提示。只留模块 1 的"精简版"输出相位/FOM/MTZ，不给模型——那 10/10 是三段链的结论，不是模块 1 单独的结论，详见 `docs/LITE_MODULE_20261112.md`。

## 3. 和 SHELXE 比在哪个位置

SHELXE 是独立链（球影响范围密度修饰 + 三肽搜索 + 多聚丙氨酸追踪），不做约束精修、不调用 Buccaneer/REFMAC。它在十案例上的自身指标是：pseudo-free CC **50.6–72.8 %**、mean FOM 0.48–0.71、最好一轮 trace 的 CC 7.5–49.0 %、输出只有 Cα（45–556 个）。

用同一把尺子（对 campaign 精修模型的平移不变复空间图相关，`work/noCCP4/compare_map_phases.py`）量十案例：

| 图 | complex CC 均值 | 说明 |
| --- | --- | --- |
| SHELXE | 0.683 | 独立链 |
| CCP4 Parrot（产品用） | **0.688** | 与 SHELXE 同级 |
| 自研内部 DM | 0.558 | 低 0.13 |
| P+ 输入相位（两个后端） | 0.272 / 0.279 | 起点相同 |

所以产品在"定相 + 密度修饰"这一层与 SHELXE 同级；差距全部落在自研替换件上（下一节）。

## 4. 自研模块（实验性，默认关闭）

| 环节 | 状态 | 实测 |

- 完整评估与复现命令见 `docs/NO_CCP4_REPLACEMENT.md`、`docs/SHELXE_BASELINE.md`。

## 5. 发布形态与限制（必须随包告知）

- 包内含 Phaser / Parrot / Buccaneer / REFMAC 二进制，`bundle.json` 写 `public_redistribution_ready: false`：**不能公开挂出**，只在内网/私有 Release/移动硬盘分发；接收方需已持有 CCP4 授权。
- 目前只有 macOS Intel 运行时；Apple Silicon 需要先有 arm64 的 CCP4。
- 二进制未签名，从网络下载后首次双击可能被 Gatekeeper 拦下，执行一次 `xattr -dr com.apple.quarantine <包目录>`。
- 十案例协议固定用 `--no-auto-hand`（手性由已精修重原子子结构确定）与 `--input-columns`；`--auto-hand` 需要带 `runtime/density/` 的完整包。
- 组装、校验、复现步骤与已知坑见 `docs/INSTALL_BUNDLE.md`。
