# dev9：双手判别与明确的密度修饰相位约束

默认仍为单一 P+ / Wang8 流程。新建完整任务执行两手的 P+、Wang8/classic40 和相同的三周期 Buccaneer 试建；所有试建输入的原自由反射实测列都置缺失。只按唯一测序残基数及预先固定的优势门槛判手，不调用试探精修，不读取 Rfree，也不比较目标蛋白参考模型。两手均无足够证据、优势不足或计算不完整时，保存候选与日志并明确报告未判定。

支持 Phaser 给出的原空间群及其对映空间群；选中后保留同一 HKL 与实测振幅、误差和原自由集标记，向后续步骤传递所选空间群。需要未支持的 HKL 重索引时拒绝静默转换。选中 DM 的缓存逐文件校验，试建模型不作为最终建模种子。

相位阶段耗时增加，因为判手需要两次密度修饰和试建。默认“仅相位”任务不执行此建模判手，保留双手 Phaser 文件但不宣称手性已解决；命令行可显式启用 `--auto-hand`，此时即使不输出最终蛋白模型，也需要包内 Buccaneer 的短试建。

新建完整任务显式使用 `ccp4` 建模参数：fast、anisotropy-correction、sequence-reliability 0.95、UNK、2 Å 建模上限和两项 3.0 的过滤阈值。第一轮不提供模型 Fc；后续有完整 HLACOMB 时使用其概率分布，缺失时回退到合法的 PHCOMB/FOM。REFMAC 精修使用冻结的工作集 DM 相位/FOM近似约束，MTZ 列标记为 DM_PHIB/DM_FOM，原自由反射相位约束置缺失。原始 SAD 似然仍独立保存，继续用于 P+ 与 DM，不能冒称精修仍使用原始 SAD 纯似然。

这是相位制约协议的明确改变：改进相位与观测并非独立信息，不把它包装为新的独立观测似然。输出记录 source_kind、相位源哈希、合并审计及精修关键词。保持固定末轮，不按最低 Rfree 挑选模型。旧保存配置和显式历史入口仍保留原建模与原始 SAD 约束协议。

界面显示两手的空间群、唯一测序数、测序/构建数与选择结果。元素、必填实验波长、自动理论 f″、可选原始观测和 MTZ 列选择继续沿用 dev8。SHELXD 子结构为外部输入；未增加自动 SHELXD 搜索或安装依赖。

本次 SSRF 案例的原自由集与 CCP4 unique1 不同。固定坐标换自由集打分只是诊断，不能作为独立 Rfree，模型可能见过新“自由集”中的反射。为严格比较，还须从头重算所选划分下的所有步骤，并明确上游相位是否使用原自由观测。Phaser 原始两手 FOM/LLG相同并不证明可以按文件顺序选手；原理参见 [Phaser 原始论文](https://journals.iucr.org/j/issues/2007/04/00/he5368/) 与 [HAND 参数文档](https://www.phaser.cimr.cam.ac.uk/index.php/Keywords#HAND)。
