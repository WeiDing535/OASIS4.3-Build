01 设置任务

提供 SAD 异常衍射数据、原始 native 与自由集、重原子模型和序列。程序分别保存原始 SAD HL 与密度修饰相位，自动接入无初始模型构建。首次整合支持已有重原子信息，使用未修饰的标准氨基酸 FASTA/PIR。native 需 F / SIGF / FreeR_flag。后续外部精修地图尚未认证为仅工作集；Rfree 不是端到端盲测指标。

无初始模型模式从实验相位开始构建；已有种子模式从所选模型继续。两种模式均调用外部 Buccaneer 构建、REFMAC 精修。每轮保留同一份原始实验 HLA / HLB / HLC / HLD；后续地图只用本任务自身上轮精修输出。此模式不是原生 PhaseBuild 从头算法。

本模式使用固定列：地图 F / SIGF / FWT / PHWT / FOM；native F / SIGF / FreeR_flag，在高级设置填写原自由集数值（默认 0）。只接受现有自由集，不生成新标记。默认 5 轮 × 10 周期，固定最后一轮模型，不按 Rfree 选模。

每轮构建后精修，并将更新图用于下一轮。
高级设置 构象库、搜索参数与自由集

地图建模读取上方选择的振幅/相位列；振幅不会再次乘以 FOM。精修阶段支持自选 F / SIGF / 自由集列。自由集使用输入文件中的现有标记。
